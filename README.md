# 🩺 AI Health Engine

AI Health Engine is a **full-stack healthcare web application** that leverages Machine Learning to predict diseases based on user-entered symptoms. The platform provides an intuitive interface where users can input symptoms, receive disease predictions, and access detailed health-related information to promote early awareness.

---

## 📌 Project Overview

AI Health Engine is designed to assist users by predicting potential diseases using Machine Learning algorithms based on the symptoms they provide.

The application allows users to:

* 🩺 Enter symptoms through an interactive interface
* 🤖 Predict possible diseases using a trained Machine Learning model
* 💊 View disease descriptions
* 💉 Get recommended precautions
* 🍎 Receive diet recommendations
* 💪 View workout suggestions
* 💊 Check suggested medications
* 👤 Register and log in securely
* 📱 Access the application on desktop and mobile devices

This project demonstrates the practical implementation of **Machine Learning** integrated with a **MERN Stack** web application.
